## 1. 要做的

### P30-1 · 读规范，写一页「差在哪」

- 新版里：怎么开始一次会话、服务端的使用说明放在哪、版本怎么协商、旧版客户端连新版服务和反过来各会怎样。
- 现在主流的几个客户端（Claude 桌面版、Claude Code、Codex、VS Code 等）各自用哪一版、什么时候不再兼容旧版——查不到就写「没查到」。
- 给出改法：怎么让两种客户端都能连、都收到路由说明。

### P30-2 · 改

- 旧版那条路一字不变地照旧能用。
- 新版那条路也能拿到同样的路由说明，并且照样记下「哪个客户端连过」（设置页靠它判断）。
- 加测试：两种客户端各模拟一遍，都能拿到路由说明；`every_tool_is_reachable_from_the_routing_text` 照旧过。

### P30-3 · 真客户端验

- 用探针进程或真客户端各连一次（连的是演示版或库副本，不连真库目录）。
- 有哪家已经只认新版，就用那一家真跑；没有就写清「新版那条只在测试里验过」。

- **验收**（`DISCOVERED-20261113-5` 的验收标准）：新旧两种客户端都能连、都能收到路由说明；现有的路由测试照旧通过。另外：`cargo test --lib`、vitest 都过；设置页「哪些 AI 连过」对两种都对。
