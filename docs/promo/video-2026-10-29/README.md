## 这两支视频要卖什么

核心主张：**你的工作在继续，AI 就应该接得上。**

英文主标题：**Think with AI. Keep the thread.**

一句产品解释：Spool 把你随手捕捉的资料、自己的判断、文件和 AI 讨论中的新结论，串在同一个项目里，让不同 AI 能基于这些上下文继续帮你工作。

观众看完应当能用自己的话解释：

1. 我可以在原来看的页面上，把文字或截图直接存进正在做的项目。
2. 时间、来源和我的批注留下来，AI 能分清资料、我的想法和它自己的建议。
3. 我可以把项目交给常用 AI；换一个 AI，也能从相同项目继续。
4. 有用的新结论可以写回；待跟进的问题、过时信息和下一步也有地方处理。
5. 最终我完成的是作品集、课程任务、申请或生活项目；Spool 留下这段过程和成果。

观众应当产生的情绪：先被“又要重新解释一遍”击中，再看到“这次真的接上了”，最后觉得“我今天就能试，先捕捉一条就可以”。

## 创意方向：Keep the thread

用一根琥珀色细线，从开场捕捉浮窗牵出，依次连接原始资料、用户批注、不同 AI、待审结果与完成的项目。随着真实操作推进，零散卡片形成可继续翻阅的卷轴。

视觉继承用户已经选定的两张概念图：

- [AI 工作流程图](../2026-10-17/spool-concept-ai-workflow.png)：米白、琥珀、纸张、实体连接、复古翻页档案。
- [每日积累图](../2026-10-17/spool-concept-daily-progress.png)：日常一点点积累到看得见的成果。

主片预计约 70% 时间展示真实软件、真实录屏或其裁切，约 30% 展示概念渲染与标题。概念渲染负责“为什么”；真实界面负责“怎么发生”。使用真实界面做透视、局部放大、景深和高亮即可，不让生成模型重画产品文字。

声音从零散的键盘和窗口声，过渡到稳定的律动。双击捕捉的两声轻击成为记忆点，结尾再次出现。避免宏大科幻、密集通知、机器代替人思考的气氛。

## 主故事：把作品集做到可以提交

全片跟随演示项目 **Portfolio site**，目标是完成三篇项目案例，得到可以用于申请的作品集预览。这个题材同时容纳研究、写作、文件、截图、代码仓库、跨 AI 讨论和成果。

用户有几个一直保留的判断：最多三个项目；保留音乐项目；暂时不做博客；每个案例说明问题、行动与结果。Spool 的价值通过这些判断在后来的 AI 建议中仍然起作用来表现。

“学习 / 找工作 / 生活”只在结尾用现有 Machine learning course、Job search、Apartment hunt 三个项目做快速横向扩展。主体不反复换案例。

最终成果镜头是演示作品集的真实本地预览和完成清单。片中不暗示 Spool 自己生成、部署了网站，也不把提交申请或获得工作当成已发生的结果。

## 对用户提出的三个比较方向的处理

| 比较方向 | 片中保留的冲突 | 最有说服力的证据画面 |
|---|---|---|
| AI 应用自己的项目 / 文件 / 记忆 | 我仍需确认信息是否跟上当前项目，以及换工具时如何接续 | AI A 写回一条新决定，AI B 随后从同一个 Spool 项目正确读到 |
| 传统笔记 | 收集和排版之后，我还需要把资料变成下一步 | 选中文字 → 双击 → 加一句“为什么对我重要” → AI 用这句判断帮助推进项目 |
| 超级 Agent | 让 AI 执行时，我想让自己的意图和改变理由一直可见 | “保留音乐项目”的原话仍在；新结论有 AI 来源；取代旧决定要经过用户选择 |

新增第四个比较角度：**不用迁移到又一个 AI，现有工具就能继续。** 在同一个项目上换 AI，比一排平台 Logo 更能证明产品价值。

不把笔记软件说成只会排版，也不否认检索复习对学习有用；突出 Spool 的任务导向即可。超级 Agent 选择 **OpenClaw** 作为研究代表：当前官方仓库足够热门，但不声称它是全市场公认第一。它也有记忆、来源机制和跨工具能力，因此主片表达“用户选择怎样保留自己的思路”，不用“别人的 Agent 不尊重你”这种无法证实的攻击。

竞品名称和具体反馈放进研究文档、视频简介或单独的比较内容。主片用概括性的情境和有来源的短卡片，约 15 秒建立痛点后立刻展示 Spool。对比只是切入口，Spool 的工作闭环才是主体。

## 两支视频的分工

| | Promo | Tutorial |
|---|---|---|
| 时长 | 2:30 | 17:00，实录按停顿可上下浮动约 1 分钟 |
| 核心问题 | 为什么我的 AI 工作需要 Spool？ | 我现在怎样完成这一套流程？ |
| 语言 | 英文配音、英文屏幕文案；另导出中文字幕轨 | 中文真人讲解、英文界面；另做英文字幕 |
| 观看门槛 | 无需知道 MCP、API、CLI | 前 5 分钟无需配置；后续按章节选择 |
| 叙事 | 从散落的信息走到完成的项目 | 同一个项目，逐个操作并展示结果 |
| 制作方式 | 真实产品素材 + 概念渲染 + 文字动画 | 真人短开场 + 清晰录屏；关键判断时回到真人 |
| 行动号召 | 创建一个项目，捕捉第一条 | 照做一次捕捉；再选 Pack 或 MCP |

## 开头与结尾的浮窗

开场是真实复制 **Welcome to Spool!** 后双击 ⌥ / Ctrl，真实捕捉浮窗出现。观众先看到软件最轻的交互，再进入叙事。

结尾同样捕捉 **Byebye 👋**，像助手轻轻告别。它是拍摄时放在演示来源里的内容，不是新增“自动欢迎 / 自动告别”功能。详细录法和避免覆盖真实数据的方法见 [03](03-demo-and-recording.md)。

## 建议先拍什么

第一优先是“同一个具体决定跨两个 AI 继续生效”的连续素材，以及“不切屏完成捕捉”的连续素材。先证明产品价值，再做概念动效；否则容易得到一支漂亮却仍然解释不清软件的视频。

这次交付范围是两支视频的完整设计文档。录屏、真人配音、引擎调用、渲染制作和成片导出有明确脚本与清单，尚未执行。产品代码、演示库和 AI 客户端配置本轮没有改动。
