## 3. 九步

### 共同的规矩

- 每一步单独一笔提交；提交前跑全套测试（`npx tsc -b`、`npx vitest run`、`cargo test` 主程序和 sidecar、`node scripts/i18n-check.mjs` 和 `--dead`、`cargo tree` 那条、clippy 不许有落在改动行上的新警告），数字比基线只多不少。开工先记基线。
- 每一处改动都要有测试，测试先红后绿（只能真手指验的，写清楚为什么测不了、截图或交给 §6）。新加的中英文字串都进字典。
- ⛔ 不起 debug 版 GUI。验 MCP 用新二进制 `--mcp` 连真库副本（记忆 §44）。
