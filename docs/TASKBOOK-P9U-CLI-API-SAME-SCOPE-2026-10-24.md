## 2. 起点（10-24 对着 `d009193` 查的）

| 功能 | 本机 CLI | API | 锁着时说什么 |
|---|---|---|---|
| 周回顾 | 有（引擎带 MCP 跑） | 有（一发，`weekly_review_via_api`） | 「本机的 Claude Code / Codex，或者 DeepSeek」 |
| 跟进 | 有（引擎带 MCP + 联网） | **没有** | 「要用本机的 Claude Code 或 Codex」 |
| 压缩 | **没有** | 有（`compress_pack_via_api`） | 「让 DeepSeek……用你自己的 DeepSeek key」 |
| 过期检测 | **没有** | 有（`stale_scan_via_api`） | 同上 |

- API 这条路：`spool-ai` 小程序发 OpenAI 那种 `/chat/completions`（Bearer key），默认 `https://api.deepseek.com` + `deepseek-v4-flash`，「思考力度」默认 `low`（发 `reasoning_effort`）。别家：OpenAI 对不支持的参数会回 400；Claude、Gemini、Kimi、通义、OpenRouter 都有兼容这种格式的地址，但每家不一样。
- 压缩 / 过期检测 / API 周回顾的提示词都是「一段 system + 一段 user → 一段字」，不需要工具 ⇒ 本机 CLI 可以拿同一段提示词跑，出来的字走同一套核对（`keep_pack_boundaries`、逐字闸）。
- 设置「AI 引擎」页：顶上「显示 AI 功能」，然后 API 那一节标题是「让 Spool 自己调 AI 压缩上下文」（像是压缩专用）+ 一段「已经装了 claude / codex……这一节是给不想装的人的第二条路」，然后才是本机引擎。两边分量不一样。

## 3. 五步

### P9U-1 · 压缩、过期检测也能走本机 CLI（Rust + 锁）

- Rust：一个「问一次模型」的入口，两种后端 —— API（`spool-ai`，现在这条）和本机 CLI（新：同一段 system + user 拼成一个提示，CLI 不给任何工具、不连 MCP、只读沙箱，拿最后一段回答）。压缩、过期检测（API 周回顾也顺带）都走这个入口，出来的字后面的核对一个字不改。
- 前端：压缩、过期检测的入口从「只认 API」改成「两条路都认」（`aiEntryState` 的 route 从 `api` 改 `any`），锁着时的话不再提 DeepSeek。
- **验收**：单元测试（CLI 后端拼提示的样子、参数里没有任何工具 / MCP）；这台用本机 Codex 真跑一次压缩、一次过期检测（用 Ocean 的订阅额度，跑之前问），结果卡和 API 跑的一样能核对。

### P9U-2 · 每个功能各自选「本机 CLI / API」（第 187 条）

- 设置里存四个选择（周回顾已有 `autoReviewRoute`，新加压缩、过期检测、跟进三个；不改库，只是 settings.json 多三个键）。默认：哪条连上用哪条，两条都连上时用本机 CLI（不花钱）。
- 每个功能的按钮旁边一个和周回顾同样的小选择器「用 本机 CLI / API」，只在两条都连上时出现；只连上一条时直接写它用的是哪条。

### P9U-3 · API 那一半：粘 key 自动认，每家都能用（第 188 条）

- 一张厂商表（只放在一处）：名字、默认地址、key 前缀、默认模型、要不要发「思考力度」那几个参数、有没有联网搜索、拉模型列表的方式。首批：OpenAI、Claude（Anthropic）、Gemini、DeepSeek、Kimi、通义、智谱、OpenRouter、自定义地址。
- 粘 key：前缀认得出（`sk-ant-` / `AIza` / `sk-or-` …）就直接定；认不出的（裸 `sk-` 好几家都用）给一个列表点一家。地址、参数自动填；模型从那家接口拉列表（`spool-ai` 加一种请求），默认挑便宜那一档；「接口地址」只在「自定义」里出现。
- 「思考力度」只在那家认这个参数时出现。旧设置（DeepSeek 地址 + 模型）读进来认成 DeepSeek，不用重填。
- 界面上所有「DeepSeek」字样（锁、周回顾、弹出块、设置）换成「API」或者那家的名字。
- **验收**：单元测试（前缀识别、旧设置迁移、每家请求体里没有它不认的参数）；每家用假 key 打一次地址（记忆 §37：回 401 = 地址对），真 key 只有 Ocean 手上那几家能真跑。

### P9U-4 · API 也能跟进，用各家自带的联网（第 186 条）

- 一发请求，带上那家的联网搜索；回来的是固定格式（结论 + 链接 + 为什么和这个项目有关；要关的跟进行、要提议的新跟进行），Spool 自己把它们放进待审（和 CLI 那条一样标「跟进」、过同一道去重闸），没有新东西就什么都不放。
- 各家接法：OpenAI（Responses 接口的 web_search）、Claude（Messages 接口的 web_search 工具）、Gemini（google_search）、Kimi（内置 `$web_search`）、通义（`enable_search`）。DeepSeek 等：跟进那一项写「这家的 key 不能联网搜，换一家或用本机 CLI」。
- 每周自动跟进（P9S-6）照这个功能自己的「本机 CLI / API」选择走。
- **验收**：单元测试（每家请求体、回答解析、放进待审的样子）；真跑要那家的 key —— 只有 Ocean 手上有的才跑，其余在回执里写明「照文档写、假 key 验过地址、没真跑过」。

### P9U-5 · 设置「AI 引擎」页：两条路分量一样（+ 截图、换装）

- 顶上「显示 AI 功能」不动。下面左右（窄窗口时上下）两块一样大、一样的写法：**本机 CLI**（P9T 那一块）｜**API key**（粘 key、认出的那家、模型、连接状态）。每块下面同一行字：「周回顾 · 跟进 · 压缩 · 过期检测」—— 两边都能做；某一家的 API 不能联网时，那一块在「跟进」后面标出来。
- 压缩专用的那几个设置（保留原文、思考力度）挪到它们管的那个地方（压缩页签 / API 那一块里），不再当成整个 API 那一节的标题。
