# Spool — 复古档案工作台

2026-10-17。三张 AI 宣传概念渲染，使用复古器物解释软件操作；不是实际产品界面截图。

本轮方向取代被否决的电脑屏幕构图。保留用户选择的原始功能版：暖米白、琥珀、纸张纤维、温润透明构件，以及中央 Your project 翻页档案机。

## 三版

1. **共享打字机** — Claude / Codex / Cursor 是同一台打字机的三个工具选择键，共用一张项目纸。最直观地表达读取、思考和补充。
2. **共享编辑案台** — 三种书写工具对应三个 AI 客户端，共用同一张项目档案。纸张、墨迹、批注和放大镜更贴近 Spool 温和的案头气质。
3. **共享校样机** — 三种可替换字模对应三种 AI 工具，共用一个进纸口；新增内容成为可审阅的新校样，强调积累和归档。

## 流程及表达边界

- Start a project → Capture & note → Your project 为入口；同一档案副本交给 AI 继续处理。
- AI 输出经 Review changes 的 Original / Proposed 对照，由 You decide 表达用户审阅；有新增内容的新卡插回原翻页档案，原始记录保留。
- Follow Up、Weekly Review 和完成项目均通过中央档案组织，线缆只作简洁的引导。
- 本机工作以同一张个人案头、共同档案与闭合纸张路径表达，不写 local / offline；这不宣称第三方 AI 推理离线。当前产品的 AI 客户端仍可能连接网络模型。
- 画面选择的是待审更正的代表性路径；普通允许的 AI append 并非全部逐条审批。
- Follow Up 需要用户触发，结果是待审提议；Weekly Review 为本机 CLI 或用户配置 API 生成的只读报告；完成项目由用户决定。图像不新增产品行为承诺。

功能事实沿用同级 ../README.md 的当前源码核对；本轮只生成和检查图片，没有执行产品功能或更改实现，也未发布。

## 记录

- PROMPTS.md：完整初次编辑提示词与参考来源。
- FINISHING-PROMPTS.md：后续路径与细节修正。
- manifest.json：最终文件、原始生成路径、尺寸与校验值。
- drafts/：初稿和保留的修订，用于溯源。
